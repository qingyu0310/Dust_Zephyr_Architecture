## 〇、执行总览

### 0.1 关键决策（定死，不再讨论）

| 决策 | 结论 |
| --- | --- |
| 架构层位置 | `zephyr_user/framework/`（submodule 管理，git 拉取更新） |
| DUST 前缀 | 架构层所有 Kconfig 符号统一 `DUST_` 前缀；业务符号（TRD_XXX/PRJ_MAIN）与 Zephyr 子系统符号不加 |
| DUST 重命名位置 | 在 `framework/` 内完成，提交 push 回各架构层仓库；**dust 保持旧 submodule 指针不动**（兜底=迁移前状态） |
| usb 协议栈 | 归位 `framework/drivers/communication/stream/usb/`，Kconfig 符号用新设计 `DUST_USB_DEVICE_STACK` 等 |
| tflm/third_party | **不迁移**，留在 dust（归属未定） |
| main/third_party | 先尝试收敛到子树，出问题放业务层 |
| 业务项目装配 | 保留 dust 机制（rsource + add_subdirectory），FW_ROOT/ZEPHYR_USER_DIR 两个变量收敛路径差异 |
| dust | 完全不动，作为迁移前兜底 |

### 0.2 执行顺序总览

```text
Phase 0  准备（备份 + push 确认）

Phase 3  维护者业务项目 zephyr_user/project
Phase 4  用户业务项目 projects/<name>
Phase 5  验证（构建 / 可见性 / 更新链路）
```

### 2.2 替换规则（关键）

对每个架构符号 `XXX`，把 **`XXX` → `DUST_XXX`**（子串替换，含 `CONFIG_XXX`、`config XXX`、`select XXX`、`depends on XXX`）。

- 只替换上表符号；**Zephyr 子系统符号（GPIO/CAN/USB/SERIAL/SPI/PWM/ZBUS/UART_ASYNC_API 等）不替换**；
- 子串包含关系（`COM_UART` ⊂ `COM_UART_DMA`、`FLT_KALMAN` ⊂ `FLT_KALMAN_EKF`、`MOD_DEV_IMU` ⊂ `MOD_DEV_IMU_*`）**按长度降序替换**，结果正确；
- 执行后必须用 2.8 验证命令确认无遗漏。

### 2.3 各层涉及文件

| 层 | Kconfig | CMakeLists | 代码 #ifdef |
| --- | --- | --- | --- |
| drivers | `framework/drivers/Kconfig` | `framework/drivers/CMakeLists.txt` | — |
| algorithm | `framework/algorithm/Kconfig` | `framework/algorithm/CMakeLists.txt` | — |
| modules | `framework/modules/Kconfig` | `framework/modules/CMakeLists.txt` | `MOD_DEV_IMU_IDENT`（代码 ifdef） |
| topic | `framework/topic/Kconfig` | `framework/topic/CMakeLists.txt` | — |
| cmd | `framework/cmd/Kconfig` | `framework/cmd/CMakeLists.txt` | `CMD_*`（shell/buzzer/flash 头文件 ifdef） |
| usb | `framework/.../stream/usb/Kconfig` | `framework/.../stream/usb/CMakeLists.txt` | — |

```cmake
cmake_minimum_required(VERSION 3.20.0)

# ---- (0) 框架与 zephyr_user 路径（位置 A：zephyr_user/project）---------
set(FW_ROOT         "${CMAKE_CURRENT_SOURCE_DIR}/../framework")
set(ZEPHYR_USER_DIR "${CMAKE_CURRENT_SOURCE_DIR}/..")

# ---- (1) 业务门禁符号 -----------------------------------------------------

# ---- (2) SDK glue（HPM 平台可选）------------------------------------------
if(DEFINED ENV{SDK_GLUE_DIR})
  set(SDK_GLUE_DIR "$ENV{SDK_GLUE_DIR}")

  set(SDK_GLUE_DIR "${CMAKE_CURRENT_SOURCE_DIR}/../../../Zephyr_HPMicro/sdk_glue")
endif()
set(SDK_GLUE_USER_DIR "${CMAKE_CURRENT_SOURCE_DIR}/../../../Zephyr_HPMicro/sdk_glue_user")

# ---- (3) BOARD_ROOT / SOC_ROOT / DTS_ROOT 指向 zephyr_user -----------------
list(APPEND BOARD_ROOT "${ZEPHYR_USER_DIR}")
list(APPEND DTS_ROOT   "${ZEPHYR_USER_DIR}")
list(APPEND DTS_ROOT   "${ZEPHYR_USER_DIR}/dts")
if(EXISTS "${SDK_GLUE_DIR}")
  list(APPEND BOARD_ROOT "${SDK_GLUE_DIR}")      ; list(APPEND SOC_ROOT "${SDK_GLUE_DIR}")
  list(APPEND DTS_ROOT   "${SDK_GLUE_DIR}")      ; list(APPEND DTS_ROOT "${SDK_GLUE_DIR}/dts")
  list(APPEND BOARD_ROOT "${SDK_GLUE_USER_DIR}") ; list(APPEND SOC_ROOT "${SDK_GLUE_USER_DIR}")
  list(APPEND DTS_ROOT   "${SDK_GLUE_USER_DIR}") ; list(APPEND DTS_ROOT "${SDK_GLUE_USER_DIR}/dts")
endif()

# ---- (4) ZEPHYR_EXTRA_MODULES ----------------------------------------------
set(ZEPHYR_EXTRA_MODULES
  "${SDK_GLUE_DIR}"
  "${SDK_GLUE_DIR}/../modules/lib/CherryUSB"
)
set(ZEPHYR_SDK_INSTALL_DIR "${CMAKE_CURRENT_SOURCE_DIR}/../../zephyr-sdk-0.16.8" CACHE PATH "")

# ---- (5) 板级 overlay / conf / board.cmake ---------------------------------
if(NOT DEFINED BOARD_CFG)
  set(BOARD_CFG ${BOARD})
endif()
file(GLOB OVERLAY_FILES   ${CMAKE_CURRENT_SOURCE_DIR}/boards/*/${BOARD_CFG}/${BOARD}.overlay)

# ---- (6) 接入 Zephyr 构建系统 ---------------------------------------------
find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})
project(my_project)

# ---- (7) 业务源码与系统入口 ------------------------------------------------
target_sources(app PRIVATE src/main.c)
target_include_directories(app PRIVATE src)
target_include_directories(app PRIVATE
  ${FW_ROOT}/init
  ${FW_ROOT}/cmd
)
target_compile_options(app PRIVATE $<$<COMPILE_LANGUAGE:CXX>:-fno-threadsafe-statics>)

# ---- (8) 装配架构层各层（门禁打开时 add_subdirectory）----------------------
if(CONFIG_${CONFIG_SYM})
  add_subdirectory(${FW_ROOT}/drivers   ${CMAKE_CURRENT_BINARY_DIR}/framework/drivers)
  add_subdirectory(${FW_ROOT}/algorithm ${CMAKE_CURRENT_BINARY_DIR}/framework/algorithm)
```

## 八、风险与回滚

### 8.1 风险

| 风险 | 缓解 |
| --- | --- |
| DUST 重命名遗漏（Zephyr 符号被误改 / 架构符号漏改） | 2.5 自检 grep；先按层小范围替换 + 单层构建验证 |
| sed 误伤注释/字符串 | 替换只针对符号名；自检确认 |
| usb bipbuf/stream.hpp 跨树 | 上移 framework（见 1.3.3） |
| module dts_root 未配置 | 用 1.3.3 的 dts_root 列表写法 |
| add_subdirectory 缺二进制目录 | CMake 显式给 `${CMAKE_CURRENT_BINARY_DIR}/framework/<layer>` |

### 8.2 回滚

```text
框架迁移出错 → dust 仍是完整可用工作区（旧 submodule 指针 + 旧符号）
    → 删除 zephyr_user/framework（可重建）
    → 业务项目模板出错 → 对照 dust 装配
```
